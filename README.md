# Plumb Anything HQ

I wanna build the most unique Plumbing local website named "Plumb Anything" using this prompt and link: Create a landing page hero section with a neo-brutalist design inspired by Swiss typography.

Design specifications:

- Bold, massive headline text (100px+) with tight tracking

- Light gray/beige background (#F0F0F0) with strong black borders

- Brutalist shadow effects (8px offset, solid black)

- Circular decorative sticker element with icon

- Two-column layout: description + giant CTA button

- Bottom card deck with colorful cards (pink, blue, yellow)

- Cards have rounded top corners and hover lift effects

- Monospace typography for labels and metadata

- Serif font for descriptive text

- High contrast black text throughout

Technical Requirements:

- React with TypeScript

- Tailwind CSS for styling

- Responsive design (mobile-first)

- Use lucide-react for icons

- Include smooth hover animations
